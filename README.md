# Quête à ISITCOM

## Installation et lancement en local

Depuis un terminal :

```bash
git clone https://github.com/codeyahya/isitc-quest.git
cd isitc-quest
git pull origin main
npm install
npm run dev
```

Vite affiche ensuite l’adresse locale dans le terminal. Ouvrir :

```text
http://localhost:5173
```

Pour mettre à jour une copie déjà clonée :

```bash
git pull origin main
npm install
npm run dev
```
